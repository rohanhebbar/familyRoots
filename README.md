# FamilyRoots

FamilyRoots is a visual family tree prototype centered on a child as the root profile. It is designed to make maternal and paternal ancestry easy to explore at different zoom levels.

## Prototype Features

- Zoomable ancestry canvas with maternal and paternal branch highlighting.
- Person tiles with initials or photos, names, birth/death dates, and short story prompts.
- Editable person detail panel for core biographical fields.
- Manual parent creation for the selected person.
- CSV import/export using the first prototype schema:

```csv
id,name,birthDate,deathDate,photoUrl,motherId,fatherId,notes
```

## Development

```bash
npm install
npm run dev
```

Use `npm run lint` and `npm run build` before publishing changes.
